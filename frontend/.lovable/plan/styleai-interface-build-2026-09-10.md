# StyleAI Interface Build

## Goal
Build the approved Pale Soft UI direction as a polished, navigable StyleAI prototype covering the core brand workflow.

## Screens
- **Homepage:** Product-to-campaign overview, featured workflow, and clear entry into the workspace.
- **Dashboard:** Campaign priorities, projected reach, recent products, and top creator matches.
- **Product detail:** Product imagery, AI-derived fashion attributes, generated commerce copy, and recommended influencers.
- **Campaign detail:** Campaign status, creator roster, deliverables, budget, and performance metrics.

## Shared experience
- Use one consistent StyleAI header, workspace switcher, and navigation across all screens.
- Keep the approved pale lavender, white, ink, and pink palette with Fraunces display type and a clean sans-serif body.
- Use realistic fashion imagery and representative sample data so every screen feels approval-ready.
- Make navigation and primary actions interactive where useful, while keeping data as a visual prototype.
- Adapt layouts cleanly for smaller screens without changing the approved desktop-first direction.

## Technical details
- Implement each screen as its own app page using the existing routing system.
- Define all visual colors, shadows, and typography through shared design tokens.
- Generate and bundle the fashion and creator imagery needed by the selected design.
- Add unique page titles and social metadata for every screen.
- Verify the finished pages visually at desktop and mobile sizes and resolve any build or layout issues.
